## Install Google Chrome Browser

```md
Open Microsoft Edge browser and Navigate to **google.com/chrome**
├── Click on **Download now**
├── Accept and Install
├── Then **Run**
├── Click on yes to continue
└── After installation is done, close the `Microsoft Edge` browser and open Google Chrome browser
```

## Install git bash
```md
open Google Chrome browser and navigate to **git-scm.com**
├── Click on **Downlod for windows** to download the installer
├── Double click on the executer package and follow the next instruction 
├── Make sure to check the **On the Desktop **shurtcut component
├── On the **Adjusting your PATH environment**, choose ***Use Git from the Windows Command Prompt***
├── On the "Configuring the line ending conversations", select "Chackout as-is, commit Unix line ending" 
└── Click on Next and finish
```

## Install VirtualBox

```md
├── Install VirtualBox
│   ├── Navigate to **https://www.virtualbox.org/**
│   │   ├── Click on *Download*
│   │   ├── click on *Windows host*
│   │   ├── Navigate to the Download folder and double click on the *installaer*
│   │   ├── Accept the agreement
│   │   ├── Follopw and accept the default configurations
│   │ 
└── Install VirtualBox Extension Pack
    ├── Also download the Extension Pack "All support platform"
    ├── Open VirtualBox from the icon of the office 
    ├── Got Extensions
    ├── Click on the Add extention button
    └── Navigate to the extension pack file downloaded > Open > Accept the License Agreement > OK
```

## Install Vagrant

```md
Navigate to google, search and download the windows installer Vagrant on **https://developer.hashicorp.com/vagrant/install**
├── Install the default version
└── Verify that Vagrant is install and works fine
    └── Navigate to **Git Bash CLI**
        └── $ vagrant --version
              Vagrant 2.4.9
```
